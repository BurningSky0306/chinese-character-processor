==========================================
  汉字属性处理工具 - 使用说明
  用于心理学实验刺激材料准备
==========================================

【工具功能】
本工具可以自动为您的汉字列表添加以下属性：
- 笔画数 (stroke count)
- 拼音 (pinyin，多音字会显示所有读音)
- 部首 (radical)
- 结构 (structure)
- 声母 (Initial consonant)
- 韵母 (final vowels)


【使用步骤】

1. 安装 Node.js
   - 访问 https://nodejs.org/
   - 下载并安装 LTS (长期支持版)
   - 安装完成后，重启电脑

2. 准备文件
   - 确保您的 Excel 文件名为：
     "Chinese character list from 2.5 billion words corpus ordered by frequency.xlsx"
   - 确保该文件在当前文件夹中

3. 安装依赖包
   - 在当前文件夹中，按住 Shift 键，然后右键点击空白处
   - 选择 "在此处打开 PowerShell 窗口" 或 "在终端中打开"
   - 在打开的窗口中输入以下命令并按回车：
     
     npm install
   
   - 等待安装完成（可能需要几分钟）

4. 运行脚本
   - 在同一个窗口中输入以下命令并按回车：
   
     npm start
   
   - 程序会自动处理您的文件
   - 处理过程中会显示进度

5. 查看结果
   - 处理完成后，会在同一文件夹生成新文件：
     "Chinese character list with properties.xlsx"
   - 用 Excel 打开该文件即可查看结果


【注意事项】

- 处理 14976 个汉字大约需要 1-2 分钟
- 如果某个汉字无法处理，该行对应的新列会显示为空
- 原始文件不会被修改，所有结果保存在新文件中
- 多音字的拼音会用逗号分隔显示所有读音
- 声母和韵母是根据第一个拼音提取的


【遇到问题？】

问题1：提示 "npm 不是内部或外部命令"
解决：说明 Node.js 未正确安装，请重新安装 Node.js 并重启电脑

问题2：npm install 安装失败
解决：可能是网络问题，可以尝试使用国内镜像：
      npm config set registry https://registry.npmmirror.com
      然后再次运行 npm install

问题3：找不到 Excel 文件
解决：检查文件名是否完全一致，包括大小写和空格

问题4：某些汉字的属性为空
解决：这是正常现象，某些生僻字可能在 cnchar 库中没有完整数据
